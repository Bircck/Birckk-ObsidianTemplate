# Appearance and plugins

## CSS snippets

All five are on by default, under Settings → Appearance → CSS snippets.

| Snippet | What it does | How to use it |
| --- | --- | --- |
| Colored Sidebar Items | Colors folders by their number prefix | Automatic. The colors are at the top of the file. |
| Daily Note Themes | A color for each weekday | `daily` plus the weekday in `cssclasses`. The daily template adds both. |
| Notebook Backgrounds | Paper and pen colors | The notebook templates, or the classes in [[202401211512 Notebook CSS Classes]] |
| CyanVoxel's General Tweaks | Small fixes to links, headings, images and callouts | `center-images` and `center-titles`, see [[202403091325 General Tweaks CSS Classes]] |
| sunset-dashboard | Styles the dashboard | Only affects the dashboard note |

The two notes in `Preloaded Classes` only exist so the classes show up in autocomplete when you type in `cssclasses`.

## Theme

It works with Obsidian's default theme. I use [Vanilla AMOLED](https://github.com/sakuraisayeki/vanilla-amoled-theme), which makes the background black. Install it under Settings → Appearance → Themes.

## Plugins

None are installed, so add the ones you want under Settings → Community plugins.

| Plugin | What for |
| --- | --- |
| [Iconize](https://github.com/FlorianWoelki/obsidian-iconize) | The folder icons. The rules are already set up. |
| [Dataview](https://github.com/blacksmithgu/obsidian-dataview) | Needed for the dashboard. Turn on JavaScript queries. |
| [Self-hosted LiveSync](https://github.com/vrtmrz/obsidian-livesync) | Sync through your own server |
| [Obsidian Git](https://github.com/Vinzent03/obsidian-git) | Backups with history |
| [Calendar](https://github.com/liamcain/obsidian-calendar-plugin) | A calendar for daily notes |
| [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) | More out of checkboxes |
| [Templater](https://github.com/SilentVoid13/Templater) | More advanced templates. The included ones don't need it. |
| [Excalidraw](https://github.com/zsviczian/obsidian-excalidraw-plugin) | Drawings, in the Excalidraw folder |
| [Homepage](https://github.com/mirnovov/obsidian-homepage) | Open the dashboard on startup |
| [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) | Settings for themes and snippets that support it |
| [Spotify Control](https://github.com/caezium/obsidian-spotify-control) | Music controls on the dashboard |

## Browser extension

[Obsidian Web Clipper](https://obsidian.md/clipper) is a browser extension, not a plugin. It saves web pages as notes, and its templates decide how each page is saved.

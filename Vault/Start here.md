# Start here

Every folder has an empty placeholder note, so fill them your own way and delete the placeholders.

- 📅 **Daily note:** run *Daily notes: Open today's daily note*. It gets its weekday's colors.
- 📓 **Notebook page:** run *Templates: Insert template* and pick Blueprint, Manila or White.
- 🌴 **Dashboard:** [[00 - Maps of Content/Sunset Dashboard|Sunset Dashboard]] needs the Dataview plugin. See [[99 - Meta/Dashboard/README|the setup]].
- 🎨 **Styles, theme and plugins:** [[99 - Meta/Appearance|Appearance]].
- 🔄 **Syncing:** see [the README on GitHub](https://github.com/Bircck/Birckk-ObsidianTemplate#syncing).

# Start here

This vault combines numbered folders, linked notes, a colorful sidebar, and an optional dashboard. All example notes are fictional; replace them as you find your own rhythm.

- [[00 - Maps of Content/Home|Home]] links the sample notes together.
- [[00 - Maps of Content/Sunset Dashboard|Sunset Dashboard]] needs Dataview and JavaScript queries enabled.
- [[99 - Meta/Appearance|Appearance]] explains styles, icons, and optional plugins.
- [[99 - Meta/Sync|Sync]] covers moving the vault between devices.
- [[99 - Meta/Credits|Credits]] collects the sources and inspiration.

Capture a thought in **05 - Fleeting**, connect useful ideas in **04 - Permanent**, and give work with a clear outcome a home in **01 - Projects**. **02 - Areas** holds ongoing responsibilities; **03 - Resources** holds references. Move finished material to **07 - Archives** when it stops being active.

Use the **Daily notes: Open today's daily note** command for a dated journal, or **Templates: Insert template** to start a project. Both use built-in Obsidian plugins.
